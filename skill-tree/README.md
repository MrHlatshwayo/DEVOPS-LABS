# DevOps Engineer Skill Tree

This directory mirrors the six modules and 51 courses listed in the repository
README. Each course has its own folder, and each lab has a Markdown file ready
for notes, commands, results, and lessons learned.

## Structure

```text
skill-tree/
├── module-01-.../
│   ├── course-01-.../
│   │   ├── lab-01-....md
│   │   └── ...
│   └── ...
└── ...
```

Folder and file names use lowercase kebab-case. Update the matching lab file as
each lab is completed.
