# Lab: Running Basic Commands

## 🎯 Lab Objectives
- What specific skill or tool was tested?
In this Lab we are using the terminal, it tests our command line skills in Linux
- What problem were you tasked to solve?
1. **Ask for Information**: Execute the `date` command to check the system time.
2. **Make Mistakes**: Intentionally run a non-existent command to understand error messages.
3. **Say Goodbye**: Use the `exit` command to properly close your session.
---

## 🛠️ Commands & Configuration Used
```shell
date (shows the date,time,timezone)
exit (closes or logs off from session)
```

---

## ✅ Results
- What was completed?
  1. **Success**: How to run a valid command (`date`) and read its output.
  2. **Failure**: How to recognize a "command not found" error (usually just a typo!).
  3. **Closure**: How to properly end your session with `exit`
- What output or verification confirmed success?
  The Terminal Closed which successfully confirmed the ouput of the `exit` command
