# Lab: Understanding the Current Working Directory

## 🎯 Lab Objectives
- What specific skill or tool was tested?
In this lab we are using the terminal, it tests our command line navigation skills in Linux
- What problem were you tasked to solve?
1. **Find your location** using the `pwd` command.
2. **Move to a new room** using the `cd` command.
3. **Verify your move** by checking your surroundings.

---

## 🛠️ Commands & Configuration Used
```shell
pwd (prints the working directory)
cd (changes the directory)
/ (absolute path used to locate)
```

---

## ✅ Results
- What was completed?
  In this lab, you mastered the first steps of navigation:
1. **`pwd`**: Your GPS. It tells you exactly where you are.
2. **`cd`**: Your legs. It moves you from one place to another.
3. **Absolute Paths**: Addressing a location starting from the root (`/`), like giving a full postal address.
- What output or verification confirmed success?
