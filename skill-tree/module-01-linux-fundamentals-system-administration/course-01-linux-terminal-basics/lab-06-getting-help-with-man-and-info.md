# Lab: Getting Help with Man and Info

## 🎯 Lab Objectives
- What specific skill or tool was tested?
  In this Lab we will be using the terminal, It will test our command line ability to find what we need in the manual of the Linux System
- What problem were you tasked to solve?
  1. **Reading Manuals**: Use `man` to access detailed documentation.
  2. **Searching**: Find specific answers inside massive manual pages.
  3. **Quick Help**: Use `--help` for instant reminders.

---

## 🛠️ Commands & Configuration Used
```bash
man (manual)
man ls (manual for ls command)
/ (to search in manual)
ls -a (list all files)
date --help (quick info on date)
--help (short info on a command)
```
