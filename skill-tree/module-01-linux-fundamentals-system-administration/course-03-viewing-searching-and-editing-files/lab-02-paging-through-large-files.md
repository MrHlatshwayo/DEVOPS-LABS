# Lab: Paging Through Large Files

## 🎯 Lab Objectives
- What specific skill or tool was tested?
  In this lab we will be using the terminal, this lab will test our ability to use pager to view large files
- What problem were you tasked to solve?
   how to open files, scroll through them, search for keywords, and exit safely.

---

## 🛠️ Commands & Configuration Used
```shell
less (open file in pager)
ls (list)
```

---

## ✅ Results
- What was completed?
  You have just mastered the `less` pager, one of the most useful tools in the Linux toolbox.
- **Open**: `less filename` to start reading.
- **Move**: **Spacebar** to flip pages, **Arrows** to fine-tune.
- **Search**: `/keyword` to find text, **n** to find the next match.
- **Exit**: **q** to quit.
