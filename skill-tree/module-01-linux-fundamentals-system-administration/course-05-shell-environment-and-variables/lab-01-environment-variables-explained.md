## ✅ Results
- What was completed?
  I have learned:
1. **Variables are containers**: They hold information like your username or preferences.
2. **The $ key**: You use the dollar sign (e.g., `$USER`) to unlock and read the value inside a variable.
3. **The Shell**: The interface you use (`/bin/zsh` or `/bin/bash`) is defined in the `$SHELL` variable.
4. **The Environment**: You can see the entire list of system settings using the `env` command.
